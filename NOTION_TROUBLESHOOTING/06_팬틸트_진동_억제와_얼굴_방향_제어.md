# 인물 박스와 Pose 흔들림으로 인한 팬·틸트 진동 억제

## 초기 문제

처음에는 추적 기준점을 다음 순서로 선택했다.

1. 두 어깨의 중간점
2. 두 골반의 중간점
3. 인물 박스 중앙

Pose 키포인트 신뢰도가 임계값 근처에서 바뀌면 기준점이 어깨·골반·박스 중앙 사이를 오갔다. 사람이 가만히 있어도 빨간 십자선이 크게 이동했고 카메라가 이를 따라 진동했다.

인물 박스 중앙만 사용하는 방법도 검토했지만, 검출 박스 자체가 매 프레임 흔들리기 때문에 중앙점도 계속 움직였다.

## 안전 영역 제어

사람을 항상 화면 정중앙에 맞추는 대신, 인물 박스를 화면 안의 안전 영역에 유지하는 방식으로 변경했다.

- 최근 3개 인물 박스의 중앙값 사용
- 팬 이동 시작: 박스가 화면 좌우 22% 경계를 넘을 때
- 팬 이동 종료: 박스가 좌우 30% 안쪽으로 복귀할 때
- 팬 방향 판단: 2프레임 연속 경계 초과
- 박스가 양쪽 경계를 동시에 넘을 정도로 크면 해당 축을 움직이지 않음

시작 경계와 종료 경계를 다르게 둬 경계 주변에서 서보가 반복해서 켜지고 꺼지는 현상을 줄였다.

## 명령 누적으로 인한 좌우 진동

AI는 약 25 FPS로 동작하지만 UART는 0.1초마다 전송했다. 과거에는 매 AI 프레임에서 각도를 변경해 전송 사이에 2~3번의 각도 변화가 누적될 수 있었다. 한 프레임당 최대 4도라면 실제 서보에는 한 번에 8~12도 변화가 전달돼 목표 영역을 지나칠 수 있었다.

다음과 같이 수정했다.

- 각도 계산도 실제 UART 전송 가능 시점에만 한 번 수행
- 한 번의 최대 각도 이동: 2도
- 안전 영역 복귀 또는 방향 전환 후 정착 시간: 300ms
- UART가 연결되지 않았을 때 내부 각도 누적 금지

경계 확인 프레임 수를 무조건 늘리는 방법은 출발을 늦출 뿐, 움직이기 시작한 뒤의 오버슈트를 해결하지 못한다. 명령 주기와 각도 계산 주기를 맞추는 것이 핵심이다.

## 틸트의 얼굴 방향 제어

전신 박스 중앙을 틸트 목표로 사용하면 카메라가 사람의 배나 골반을 향해 시연성이 떨어졌다. 별도의 얼굴 모델을 추가하지 않고 인물 박스 높이로 얼굴 위치를 추정하도록 변경했다.

- 추정 얼굴 위치: 인물 박스 상단에서 전체 높이의 약 10% 지점
- 틸트 이동 시작: 추정 얼굴이 화면 높이의 22~42% 범위를 벗어남
- 틸트 이동 종료: 추정 얼굴이 화면 높이의 28~36%에 들어옴
- 틸트 방향 판단: 3프레임 연속 범위 초과

빨간 십자선은 안정화된 추정 얼굴 위치를 표시한다. 팬 제어는 인물 박스 좌우 경계를 사용하고, 틸트 제어는 추정 얼굴의 화면상 높이를 사용한다.

## 주요 조정값

환경에 맞춰 다음 값을 조정한다.

- 팬이 너무 늦게 반응함: 팬 시작 경계를 더 안쪽으로 이동
- 팬이 순간적인 박스 튐에 반응함: 팬 확인 프레임 증가
- 카메라가 목표를 지나침: 최대 이동 각도 또는 gain 감소
- 방향 전환 후 진동함: 정착 시간 증가
- 얼굴이 화면에서 너무 높거나 낮음: 얼굴 복귀 범위 조정
- 추정 얼굴점이 부정확함: 인물 박스 높이 대비 얼굴 비율 조정
