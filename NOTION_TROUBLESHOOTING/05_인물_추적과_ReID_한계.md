# 얼굴 추적에서 전신 인물 추적으로 전환

## 이전 방식

- YuNet: 얼굴 위치 검출
- SFace: 얼굴 특징 추출
- 얼굴이 보일 때만 추적 가능

얼굴이 보이지 않는 뒷모습이나 전신 이동을 추적하기 어려워 인물 Pose 방식으로 전환했다.

## 현재 방식

- YOLO11n Pose TensorRT: 인물 박스와 17개 자세 키포인트 검출
- ByteTrack: 프레임 사이의 인물 위치를 연결해 ID 유지
- HSV 192차원 특징: 인물 박스의 상의·하의 영역 색상 비교

YuNet과 SFace 소스 파일은 남아 있지만 현재 웹 서버의 실행 경로에서는 호출하지 않는다.

## ByteTrack과 ReID의 역할 차이

ByteTrack은 선택한 사람이 화면 안에서 계속 검출되는 동안 위치와 움직임을 이용해 같은 ID를 유지한다. 사람이 가만히 있어도 추적할 수 있다.

옷 색상 특징은 다음 상황에서만 보조적으로 사용한다.

- 화면 밖으로 잠깐 나갔다가 다시 등장
- 다른 사람에게 가려져 ID가 변경됨
- 순간적인 검출 실패 후 새 ID가 부여됨

현재 재연결 조건은 다음과 같다.

- 마지막 검출 후 3초 이내
- 색상 유사도 0.86 이상
- 두 번째 후보보다 유사도가 0.06 이상 높음

## 현재 ReID의 한계

현재 방식은 사람 윤곽을 분리하지 않고 인물 박스 내부의 위·아래 영역에서 색상 히스토그램을 만든다.

- 박스 내부 배경이 특징에 섞일 수 있음
- 조명과 자세 변화에 영향을 받음
- 비슷한 옷을 입은 사람을 구별하기 어려움
- 얼굴만 보이면 저장된 상의·하의 특징과 비교하기 어려움
- 3초가 지나 새 ID로 등장하면 자동 재연결하지 않음

따라서 현재 기능은 장시간·다중 카메라 신원 식별이 아니라 짧은 가림과 ID 변경을 보완하는 저비용 방식이다.

## 개선 방향

정확도가 더 필요하면 다음 순서로 개선한다.

1. Pose의 어깨·골반 키포인트로 실제 몸통 영역만 잘라 배경 혼입 감소
2. 몸통이 충분히 보일 때만 옷 특징 갱신
3. 여러 프레임 연속으로 같은 후보일 때만 재연결
4. 필요하면 학습된 Person ReID 모델 도입
5. 얼굴만 보이는 근거리까지 식별해야 한다면 얼굴 특징을 보조 정보로 결합

학습된 ReID 모델은 정확도를 높일 수 있지만 Jetson의 추론 부하와 모델 관리 비용이 추가된다.
