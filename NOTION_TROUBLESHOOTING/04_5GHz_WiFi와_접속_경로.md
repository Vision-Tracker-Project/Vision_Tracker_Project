# 5GHz Wi-Fi 전환과 Jetson 접속 경로

## 기존 문제

Jetson이 2.4GHz Wi-Fi의 채널 4에 연결되어 있을 때 급격한 화면 변화에서 전송 품질이 불안정했다. 신호 세기는 강했지만 TCP 재전송과 패킷 순서 변경 흔적이 확인됐다.

Jetson의 무선 어댑터는 Realtek RTL8822CE이며 5GHz 802.11ac와 80MHz 채널을 지원한다.

## 적용한 5GHz 연결

- SSID: `KCCI501_5G`
- 채널: 36
- BSSID: `B0:38:6C:4E:6A:02`
- Jetson 주소: `192.168.0.118`

전환 후 확인된 링크 예시는 다음과 같다.

- 주파수: 5,180MHz
- 신호: 약 -49dBm
- RX: 약 780Mbps
- TX: 약 526Mbps

5GHz 전환 후 영상이 체감상 크게 부드러워졌다. 다만 PC 브라우저의 1~2초 정지는 별도의 Windows 프록시 자동 검색 문제였으므로 네트워크 품질과 브라우저 설정을 분리해 진단해야 한다.

## 연결 확인 명령

```bash
iw dev wlP1p1s0 link
```

출력의 `freq`가 5,000MHz보다 크면 5GHz 연결이다.

```bash
iw dev wlP1p1s0 get power_save
```

Wi-Fi 절전이 켜져 있으면 실시간 통신 시험에서는 끈 상태와 비교할 수 있다. 절전이 항상 문제의 원인은 아니므로 변경 전후를 같은 조건에서 측정한다.

## 사용 가능한 접속 주소

환경에 따라 다음 경로를 사용할 수 있다.

| 경로 | 주소 |
|---|---|
| Jetson Wi-Fi | `http://192.168.0.118:8000` |
| PC와 Jetson의 유선 LAN | `http://10.10.15.50:8000` |
| Jetson USB 네트워크 | `http://192.168.55.1:8000` |

PC가 `10.10.15.10`, Jetson이 `10.10.15.50`이라면 같은 유선 대역이다. USB 연결 시 PC는 보통 `192.168.55.100`, Jetson은 `192.168.55.1`을 사용한다.

서버는 `0.0.0.0:8000`에서 대기하므로 서비스 재시작 없이 사용 가능한 인터페이스 주소로 접속할 수 있다.
